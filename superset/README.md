# BI Layer

Connect Apache Superset, Metabase or Power BI to the Gold schema.

Suggested dashboard tabs:

1. Executive Overview
2. Learner Engagement
3. Course Performance
4. Assessment Effectiveness
5. Revenue & Enrollment
6. Content Drop-off

Recommended filters:
- Date
- Country
- Course
- Category
- Difficulty
- Instructor
- Learner role

Use Gold tables for dashboard datasets and avoid direct dashboard access to raw event tables.
